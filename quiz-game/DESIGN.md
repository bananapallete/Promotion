# 디자인 스타일

참고: Sprout Lands UI(크림 종이·나무 테두리), 도트 HP 바(하트 + 칸 눈금), 디더링 나무.

## 원칙
- 모든 그림은 도트. 도트 1개 = 화면 2px, 한 칸(BU) = 24도트 = 48px. 캐릭터·맵·이펙트가 같은 도트 크기를 쓴다.
- 모든 도형에 남색 윤곽선(`--navy` / `THEME.ink`). 빛은 왼쪽 위, 음영은 4x4 디더링 4단계.
- 계단식 그림자: 둥글게 번지지 않고 아래로 3~4px 단단하게 (`box-shadow: 0 4px 0`).
- 글자는 짧게 (CLAUDE.md의 UI 규칙).

## 구성요소
- **패널**: cream + 3px wood-dk 테두리 + 안쪽 2px cream-hi + 아래 그림자. 모서리 8px.
- **버튼**: cream-hi + wood 테두리, 누르면 3px 내려앉음. 확인은 leaf, 위험은 rose.
- **체력 바**: 5칸 눈금. 아래에 탄창(얇게)과 대쉬 게이지가 이어지고 내 것에만 보인다. 내 것은 크게, 남의 것은 0.72배. 30% 이하는 밝은 빨강.
- **아이템**: 동전과 같은 14x14 도트(윤곽선·하이라이트·그늘). 하트 = 체력 30% 회복, 신발 = 5초 1.4배.
- **공격 범위**: 공격 범위는 테두리 없이 면(반투명)으로만 그린다. 근접은 항상 맞는 부채꼴을 보여 주고, 공격이 끝나도 0.15초 잔상이 남는다.
- **맵 장식**: 나무·덤불·바위·그루터기·꽃·버섯. 고정 난수로 배치, 구역 밖에만, 부딪히지 않음.
- **궁극기**: 때린 피해만큼, 맞은 피해는 절반만큼 충전. 보라색 게이지(준비되면 금색)와 버튼이 차오르고, 준비되면 이름 옆 ★이 뜬다. 쓰면 이름이 크게 뜨고, 범위는 테두리 없이 면으로 표시한다.
- **궁극기 이펙트**: 모두 코드로 찍는 도트(도트 1개 = 3px, 4x4 디더링, 남색 윤곽선). `src/ultFx.js`에 폭발(불꽃·별·알 3색), 별똥별·알 낙하, 지진(갈라진 땅·튀는 돌·먼지 고리), 충격 고리, 불꽃·화살비, 오라(발밑 고리·반짝임), 돌진 속도선이 있다.
- **윤곽선 규칙**: 모든 도트 그림의 바깥 윤곽선은 1도트 폭, 블랙에 가까운 `#14122b`. 캐릭터 시트는 `tools/unify_outline.py`로 통일한다(바깥 1도트 띠 중 이미 어두운 픽셀만 바꿔서 다리·꼬리 같은 가는 부분과 색을 지키고, 바닥 그림자와 밝은 이펙트는 제외). 시트를 새로 만들면 `unify_outline.py` → `shrink_png.py` 순서로 다시 돌린다.
- **달리기 게이지**는 `RUN_DRAIN`(1.4)배 빨리 닳는다. 게이지가 없는 대쉬 캐릭터와의 균형용. 선택 화면의 "N초 달리기"는 이 배수를 반영한다.
- **채널링 궁극기**(흑발 소녀·강아지·시바견): 서서 시전하는 동안 느려지고(0.3~0.7배), 기절하면 끊긴다. 전용 `ult` 모션 시트를 쓴다(`tools/make_ult_sheets.py`).
